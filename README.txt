MAHJONG WAYS 2 — ARCADE DEMO
=============================

วิธีเปิด:
1. แตกไฟล์ Mahjong_Ways_2_Demo.zip
2. เปิด index.html ด้วย Chrome, Edge, Firefox หรือ Safari
3. เล่นได้ทั้งมือถือและคอมพิวเตอร์ โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม

ฟีเจอร์ในเดโม:
- วงล้อ 5x4 และระบบ ways แบบสาธิต
- Wild, Scatter และ Free Spins
- Cascade (สัญลักษณ์ที่ชนะหายและเติมใหม่)
- ตัวคูณ, เครดิตทดลอง, ปรับเดิมพัน, Auto/Stop
- ตารางวิธีเล่นและรีเซ็ตเครดิต

ข้อจำกัด/หมายเหตุ:
โปรเจกต์นี้เป็นเกมจำลองที่ออกแบบขึ้นใหม่เพื่อสาธิตแนวทางการเล่น
ไม่ใช่เกมแท้หรือซอฟต์แวร์ของ PG Soft และไม่ได้คัดลอกโค้ด ภาพ เสียง
หรืออัตราจ่ายจริง ไม่มีเงินจริง ไม่มีฝากถอน และผลสุ่มไม่ใช่อัตราจ่ายจริง
